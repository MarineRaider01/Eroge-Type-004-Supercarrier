# Eroge-Type-004-Supercarrier
Type 004 Supercarrier 0.11.2 | First Closed Beta

Key Features
• Four catapult tracks, four arresting wires, three deck-edge elevators, and a stern deck spawn point. The VL-49 Tarantula can launch from the stern deck.
• Equipped with day/night lighting, compartment flooding and hull breakup, plus 30 mm CIWS, IRM-S2, and two LY-1 laser close-in weapon systems.

Prerequisites and Installation
• The reference environment is Nuclear Option 0.34.6. Please install BepInEx 5, Blueprinter 2.1.2, and Aryx FS-41 Eclipse 1.1.9. 004 is an add-on mod for FS-41 Eclipse.
• Place the bundled 004 DLL into Nuclear Option\BepInEx\plugins, keeping only one copy of the 004 DLL. In the mission editor, the ship is named Type 004 Supercarrier; in the spawn point list it appears as Type 004 Supercarrier Flight Deck.
• For multiplayer, make sure the host and clients use the same versions of 004 and the prerequisite mods.

Closed Beta Feedback
The LY-1 adjustments in 0.11.2 have passed compilation and offline clearance checks. If you encounter issues with loading, aircraft spawning, takeoff/landing, or lasers, please include the game and mod versions, reproduction steps, and BepInEx\LogOutput.log.
